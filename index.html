Mentality Core

Mentality Core runs the day-to-day of Mentality Studios: who's doing what each week, who's away, what's up for auction, and who's bringing people in.

Built and maintained by MentalityJr. Every feature is a slash command, so there's nothing to memorise. Type / and it's there.

Add the bot
01 — Features

Built for the server

Every feature is a slash command. Type / and it's there.

01

Quotas

Log every event or session with a screenshot. Weekly reports, with strikes handled for you.

02

Leave

Request time off with a form. Approved leave pauses your quota, so you're never struck while away.

03

Auctions

Live bid buttons and a highest-bid tracker. Nothing is charged during a bidding war. Only the winner pays.

04

Applications

Role applications with requirement screens, cooldowns, and results sent straight to each team.

05

Tickets

Pick a category, get a private channel, claim it, close it. Only the right roles can see it.

06

Invite races

Run an invite competition with a live leaderboard. People who leave take their credit with them.

07

Moderation

Warn, timeout, kick, ban. Every action gets a case number, with a full history for each member.

08

Fun

8-ball, dice, coin flips, reminders, avatars and server info, one slash command away.
